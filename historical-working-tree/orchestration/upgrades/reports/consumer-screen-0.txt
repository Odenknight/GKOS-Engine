1: # Provisional Observatory contracts
3: Version: observatory.event.v0 / observatory.receipt.v0. These are a replay-wrapper contract, not normative GKOS artifacts. The GKOS Standard has GKX-CBOR-1 canonical encoding; this browser-oriented JSON wrapper deliberately does not claim that identity or conformance. No upstream Engine ran to produce these fixtures.
5: Canonicalization observatory.canonical.v0 uses UTF-8 JSON with no whitespace, ASCII object keys sorted lexicographically, unchanged array order, JSON string escaping, Unicode scalar strings, null/booleans, and safe integers only (no negative zero). No Unicode normalization. Float values, unsupported types, non-ASCII keys and lone surrogate code points are rejected. SHA-256 is lowercase hex over canonical receipt bytes, excluding the surrounding bundle and trailing newline. The bundle is {canonicalization,receipt,digest,signature:null}. Signature must be null in this release. Hash equality establishes integrity relative to the supplied digest, not origin, truth, certification or resistance to a party replacing both data and digest.
9: Events require schema_id, event_id, session_id, sequence starting at one, event_type, actor_role, subject_ref, decision and reason_code (nullable), correlation_id, corpus_digest, policy_digest, engine_build_digest:null, fixture_build_digest, recorded_time, time_source:fixed_fixture, visibility:public and message. Public session identifiers are deterministic replay identifiers, not issued interactive credentials.
11: The fixed-fixture validator rejects missing or extra event fields. A session is 32 lowercase hex characters; every event has the same session and correlation identifier, and its unique ID is session plus colon plus sequence. Subject references use the public MSR-NNN catalog form. Actors match the recorded input role. Recorded times must be valid UTC whole-second timestamps. Intermediate decisions/reasons are null; the final decision is permitted/refused with a declared policy reason. The ordered event manifest must match every event ID and canonical digest exactly, with no duplicates, omissions or extra fields. Both Node and independent Python verifiers enforce these rules even if an attacker recomputes the outer digest.
15: Public manifest records contain plain text, never HTML. Render textContent. Links point only between public records. A known_protected record has a fixed catalog projection and no protected links. Undisclosed records have no public projection, counts, filenames or events. Generic lookup returns the identical status/body for absent and undisclosed requests; this is not a full timing-side-channel claim.
17: corpus/build/artifacts.json pins exact public file bytes outside the public tree. Operators must authenticate/pin that manifest separately. A changed artifact plus changed trust anchor cannot be detected by unsigned hashing alone.
