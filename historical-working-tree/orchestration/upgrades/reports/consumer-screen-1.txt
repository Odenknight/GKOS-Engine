5: An authenticated identity has a sensitivity ceiling. A source is visible only when its effective classification is at or below that ceiling and the operation's capability is allowed. Thus internal permits public and internal; secret permits all seven classifications. Missing or invalid source classification remains fail-closed under the Engine's effective classification rules.
7: This is an inclusive ceiling, not an exact-classification selector. It does not mean “show only secret.” Exact-only access would require an additional explicit operator policy; the current MCP search schema does not expose an exact-classification option. Optional path_include only narrows retrieval paths and never raises the credential ceiling.
9: Persisted identities default to internal unless the operator explicitly chooses another supported ceiling. Raising a particular identity to secret is an explicit authorization change. It does not change all identities, bypass required mcp.read capability, authorize writes, repair conflicting authored records, or publish results into the static Observatory corpus.
11: The local embedding indexing ceiling is separate: a trusted local model may index through secret when the owner authorizes it, while each querying identity remains constrained by its own ceiling before ranking, snippets, citations and note reads. A secret-indexed vector is not automatically public.
