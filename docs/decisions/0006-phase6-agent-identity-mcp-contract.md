# ADR 0006: Phase 6 identity and MCP contract pack

- Status: accepted for F1 contract implementation only
- Contract: `GKOS-AGENT-IDENTITY-MCP-CONTRACT-1.0.0-draft.1`
- Entry commit: `808d875b557f4cfd2bb0addccba44d70c9748f35`

## Decision

F1 freezes a deterministic, manifest-bound contract pack containing strict Draft 2020-12 schemas, canonical and adversarial fixtures, the 32-operation core inventory, the seven-required/16-deferred tool registry, the 53-code/34-alias closed error projection, and contract-only descriptions of native stdio and loopback Streamable HTTP.

F1 does not implement authority persistence, credential processing, migration, sessions, an MCP listener, effects, or platform ACL behavior. Those claims remain unavailable until their governed later phases qualify product code.

The generator is the sole source for all 34 pack leaves. The manifest hashes the other 33 leaves and itself is excluded. Generated bytes contain the frozen source-input coordinate, never a future result commit or hosted run.

## Security boundary

Secret wire values are absent from schemas, fixtures, logs, evidence, and archives. Opaque record and scope references encode no path. Restore and bootstrap contracts require protected no-replace client locator handoff, but F1 performs no handoff. All object acceptance paths are closed.

## Consequences

Any change to a generated leaf requires updating the generator and rerunning reproducibility, schema, secret-scan, inventory, archive, and protected-path gates. Contract acceptance remains an independent reviewer decision.
