# Update — GKX 2.0.0

## Current state

GKOS-Engine 2.0.0 establishes GKX as the only schema and runtime namespace.
The CLI is `gkx`; record frontmatter uses `gkx_version`; engine state is kept
under `.gkx`; and diagnostics use `GKX-*` identifiers.

The deterministic core remains platform-neutral, offline-capable, and separate
from the optional intelligence sidecar. The sidecar produces proposals only;
it cannot author or approve a change.

## Operator action

Before adopting 2.0.0, update record frontmatter, state directories, command
scripts, imports, and diagnostic automation to the GKX 2.0 contract. Rebuild
the package before using the command-line interface or SEA sidecar.
