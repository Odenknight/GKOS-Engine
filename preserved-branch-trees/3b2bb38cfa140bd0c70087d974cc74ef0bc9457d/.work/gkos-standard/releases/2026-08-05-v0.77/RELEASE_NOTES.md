# Release notes — GKOS-2026-08-05 v0.77

**Authorized developmental publication; non-consensus.** The intended `v0.77`
tag, push, and hosting-provider release object are deliberately not created by
this worktree.

v0.77:

- records R13 as an accepted v0.x development decision;
- requires incomplete conformance runs to report `UNEVALUATED`, claim no
  affected profile, and exit non-zero;
- keeps fixture catalog 0.1.1 as a starter, non-qualifying catalog;
- establishes and records the permanent `GKOS-CONFORMANCE-001..003`,
  `GKOS-IDENTITY-001..004`, and `GKOS-LINEAGE-001..003` allocations;
- keeps implementation diagnostics and observations in a separate
  non-normative Engine adapter map;
- requires lowercase UUIDv7 for newly authored GKX note identities while
  preserving valid lowercase UUIDv4 legacy identities and broad relationship
  targets; and
- preserves lineage branches without an authoritative timestamp, UUID, lexical,
  or implementation tiebreak.

It does not qualify any implementation, make the reference Engine normative,
close the independent-implementation gate, or include or ratify any portfolio
registry. The v0.76 package remains immutable.
