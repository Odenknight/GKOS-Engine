# GKX 2.0 naming policy

R14 makes GKX 2.0 the sole current machine namespace for GKOS. Current
documents, schemas, fixtures, adapters, and implementations use
`gkx_version`, `.gkx/`, `GKX-*`, and `gkx`.

Prior release directories and superseded decision/review records are preserved
as history. They are not current conformance inputs and do not create aliases.
